A parameter is a value you send. Its type tells you what kind of value to use, such as text (string), a whole number (integer), true/false (boolean), or a list ([]). Returns describes the value you get back. “Deprecated” means an older method is still listed for clarity, but new code should use its replacement.

GET looks up information, POST sends or creates something, PATCH changes part of something, and DELETE removes something. Search by task name, such as “reset password” or “add workout.”

On backend entries, select Python view · … to jump to the view class that handles the request. Each class appears once, describes what its requests do, and links to the source. Data models describe what the server saves; serializers describe how request and response data is checked and shaped.

The Backend methods section explains the request flow and calls out meaningful helpers and serializers. Use the Backend API section for each request’s field types, return type, and HTTP results.
